    Method

    Data. 707,107 regular-season pitches from 829 MLB pitchers (2025 Statcast via Baseball Savant), aggregated to one row per pitcher and pitch type (min. 100 pitches).

    Comps. Standardized distance on velocity, induced vertical break, horizontal break, spin, release height and extension within the same pitch family; movement weighted most. Missing measurements (e.g. no release data) are left out of the distance.

    Stuff+. Modeled on tjStuff+: a gradient-boosted model trained on every 2025 MLB pitch predicts expected run value (the league-average value of each count and result, so batted-ball luck is removed) from velocity, spin, induced vertical break, horizontal break, release height and side, extension, and separation from the pitcher's primary fastball. Pitch type, location and count are not inputs. Each pitch type is scored from its average traits over the selected dates, MLB arsenals the same way, then scaled so 100 is the average MLB pitch and 10 points is one standard deviation. On pitchers held out of training, Stuff+ correlates r = 0.356 with expected run value per 100 pitches (r = 0.15 with raw run value). Traits a bullpen file doesn't record are filled with the MLB average for that pitch family. The model runs in your browser, so changing dates re-grades your averages instantly.
